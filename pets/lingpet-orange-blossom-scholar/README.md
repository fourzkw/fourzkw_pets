# 橙花书姬

![示意封面](previews/cover.png)

角色归属：**Claude**。

橙色长发与花朵发饰，手持书本、身着橙白裙装的 Q 版书姬。

## 动作与显示

- 会话动作：待机、思考、执行工具、等待输入、等待审批、完成、异常、睡眠。
- 显示版本：原图。
- 当前未包含专属点击、摸头动画。

## 安装

[下载 1.0.1 桌宠包](https://github.com/fourzkw/fourzkw_pets/releases/download/orange-blossom-scholar-v1.0.1/lingpet-orange-blossom-scholar-1.0.1.petpack)，在灵伴桌宠市场选择“导入本地包”，然后到形象列表中选择此形象。

形象 ID：`lingpet-orange-blossom-scholar`。同一形象的动作更新沿用该 ID，不另建形象条目。
