# 灵伴桌宠作品集

包含 6 个独立形象。

1. 将 lingpet-index.json、pets/、.gitignore 和此 README 提交到公开 GitHub 仓库。
2. 在该提交上创建标签 collection-v1 并发布正式 Release。
3. 将 release-assets/ 中所有 .petpack 上传为该 Release 的附件。无需将大包提交到 Git 历史。
4. 在灵伴市场提交仓库链接，各形象会独立校验和展示。

更新一个形象时，增加它的包版本号，更新索引中该项的版本、资料、标签和附件；其他形象可继续引用旧标签。索引应包含在最新正式 Release 对应的提交中。
